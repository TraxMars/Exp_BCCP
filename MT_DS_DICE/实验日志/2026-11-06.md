## 4. 结论
- **V0 对照基线已确定**（6/6 完成，commit 49758b3）：LA_8l test nms0 Dice 89.38 ± 0.20，Pancreas_6l 80.64 ± 0.16。之后的实验如果相对 V0 的差值在 0.2 个点左右，难以与 seed 间差异区分。
- **V1 探针没有改变训练结果**（与设计预期一致）：两个数据集的 test 指标（nms0 / nms1）、最佳验证 Dice 及其步数、最后 5 次验证均值、6 项诊断中位数，都与 V0 seed_42 完全相同，配对差值全部为 +0.00。但 README 规定的正式验收（`tests/compare_csv.py` 逐列比对 training_metrics.csv）还没有运行，所以零干扰在 15000 步规模上**尚不能正式下结论**。
- **V1 判据**（README "Criteria (fixed before the V1 runs)"，要求两个数据集都成立；数字为 6k–15k 中位数，来自 summary/V1.md）：
  - Forward，signed，τ* = 0.05：
    - contamination ≤ uniform：LA 0.083 ≤ 0.088 **通过**；Pancreas 0.099 ≤ 0.104 **通过**。
    - contamination ≤ none − 0.05：LA 0.083 vs 0.100 − 0.05 **不通过**；Pancreas 0.099 vs 0.156 − 0.05 **通过**。
    - swap ≥ 0.1：LA 0.039 **不通过**；Pancreas 0.043 **不通过**。
  - Forward，unsigned，τ* = 0.05：
    - contamination ≤ uniform：LA 0.112 ≤ 0.500 **通过**；Pancreas 0.160 ≤ 0.500 **通过**。
    - contamination ≤ none − 0.05：LA 0.112 vs 0.100 − 0.05 **不通过**；Pancreas 0.160 vs 0.156 − 0.05 **不通过**。
    - swap ≥ 0.1：LA 0.040 **不通过**；Pancreas 0.045 **不通过**。
  - → Forward：**不通过**（两个数据集都不成立）。
  - Reverse，unsigned，G=4，τ=0.1：
    - correction_mass > harm_mass：LA 0.0058 vs 0.0067 **不通过**；Pancreas 0.0081 vs 0.0120 **不通过**。
    - correction_rate（conf095）≥ 0.5：LA 0.005 **不通过**；Pancreas 0.009 **不通过**。
    - cos_ul_true（wrong）> 0：LA 0.616 **通过**；Pancreas 0.817 **通过**。
    - cos_ul_true > cos_pl_true（wrong）：LA 0.616 > −0.636 **通过**；Pancreas 0.817 > −0.597 **通过**。
  - → Reverse：**不通过**。
  - 敏感性风险标志（bypass_ratio < 0.2）：LA 2.383 / 3.911，Pancreas 1.319 / 2.769，都没有触发。
  - **决策**：forward 不成立 → "stop and discuss"（备选方案：只用 bucket profiles，ablation level 2）。这只是 seed 42 一个 seed 的结果，但判据事先规定就用 seed 42，所以按规则执行。
- **解剖分析的决策规则**（README "Decision rules (fixed before the run)"，3 个 seed 的均值）：
  - 规则 1（主导误差类型，share > 0.5）：LA block 0.515 ± 0.027，Pancreas block 0.658 ± 0.023 → 两个数据集都是 **block 主导**。LA 的 0.515 只比阈值高一点，3 个 seed 的标准差是 0.027，所以 LA "block 主导"的判定不够稳。
  - 规则 2：block 主导 → 需要新信息（形状 / 位置先验）；U→L 最多可达 LA 0.941、Pancreas 0.954 的 ΔDice。
  - 规则 3（A ≥ 0.70；非 entropy 信号还要求 ≥ A_entropy + 0.05）：
    - LA：flip_eval 0.711、tta_train 0.709 **通过**；entropy 0.603、ds_disagreement 0.575 不通过。
    - Pancreas：entropy 0.707、flip_eval 0.811、tta_train 0.802 **通过**；ds_disagreement 0.686 不通过。
    - → 用这些信号对伪标签做可靠性加权是可行的。LA 的 flip_eval / tta_train 只比 0.70 高 0.01 左右，余量很小。
  - 规则 4（结合 V1）：要进入 V2，需要 V1 为 go，并且两个数据集的 non-block 占比都 ≥ 0.5。实际 V1 为 stop，non-block 占比 LA 0.485、Pancreas 0.342 → **不通过，转入讨论**。
- 这些解剖结论基于第 15000 步的 Teacher，不是 test 所用的最佳验证模型（Pancreas seed 42 的最佳步是 11800），只代表训练末期 Teacher 的误差结构。
