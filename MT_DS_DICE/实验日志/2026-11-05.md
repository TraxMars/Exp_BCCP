## 4. 结论
- **V0 对照基线已确定**（MT_DS_PL，commit 49758b3，3 个 seed 全部完成，没有空预测）：
  - LA_8l：test Dice 89.38 ± 0.20，HD95 9.07 ± 1.62（nms0）/ 7.35 ± 0.44（nms1）；
  - Pancreas_6l：test Dice 80.64 ± 0.16，HD95 5.98 ± 0.05（nms0）/ 6.79 ± 0.89（nms1）。
- **seed 之间差异小**：Dice 的 std 在两个数据集上都 ≤ 0.2。之后的实验相对 V0 的配对差值如果只有 0.2–0.3 个点，很难与 seed 噪声区分。
- **nms1 后处理的影响随数据集不同**：
  - LA 上 nms1 稳定降低 HD95 的均值（9.07 → 7.35），并大幅缩小 std（1.62 → 0.44），Dice 小幅上升（+0.20）；
  - Pancreas 上 nms1 反而使 Dice 下降（−0.18），HD95 上升（5.98 → 6.79，主要来自 seed_500：5.98 → 7.81）。
- **后期验证 Dice 有回落**：所有 run 的 test nms0 Dice 都等于各自的最佳验证 Dice（验证在测试集上进行，test 用最佳验证模型；这是模型选择后的结果）。最后 5 次验证的均值比最佳值低 LA 0.73、Pancreas 1.72 个点。Pancreas 3 个 seed 的最佳步都早于 15000（10400–14200），说明后期验证 Dice 有明显回落。
- **判据**：
  - V0：未事先设定判据（README.md / CHANGES.md 中没有 V0 的预期数值或通过条件）。
  - V1：判据已在 README.md "Criteria (fixed before the V1 runs)" 中事先写好（未提交），要求 LA_8l 和 Pancreas_6l（seed 42）都成立。V1 尚未运行，各项判据目前都没有数据。
